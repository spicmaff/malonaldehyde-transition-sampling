# Популярная редакция научного сайта

Исходная публикация: `51c96a7034567006b803a92124b67e2333ba7b4e`.

Изменения относятся к изложению и интерфейсу. Исторические массивы геометрий,
энергий, сил, метрик и модели сохраняются без изменения. Предыдущие манифесты
сохранены; новый ограниченный слой `POPULAR_READING_DELTA.tsv` фиксирует
родительские и текущие хеши файлов интерфейса и его проверок.

Первый экран объясняет молекулу и постановку эксперимента простым языком.
Статический график показывает исходные девять опор трёх энергетических
профилей на одинаковых осях, с разными маркерами и стилями линий.
Раздел Optimization объясняет компромисс между остатком и штрафом;
точные значения, состояния и математические детали раскрываются отдельно.
Он использует опубликованные агрегаты и не заявляет нового native replay
или улучшения внешней точности COV. Служебные архивные инвентаризации убраны
из читательского маршрута. Evidence сохраняет существенные определения,
настройки расчётов, источники и команды проверки. Эссе и загрузка строятся
из одного английского текста.

Подтверждённые дефекты: несохранение кадра и атома в ссылке force viewer;
неверная статическая геометрия и пустые числа до загрузки скриптов;
жёстко заданное описание центрального PBE для других геометрий;
неподходящая ссылка верификации Train60; слабая обводка светлых атомов H.

Проверки:

```sh
python -B -m unittest discover -s tests -q
python -B tools/site/test_site.py
python -B tools/run_public_selftests.py .
node --test tools/site/test_editorial.mjs tools/site/test_payload_validation.mjs tools/site/test_core.mjs
python -B tools/build_research_site.py --out _site
```

Браузерные сценарии выполняются штатным `research-site` CI. Новый
`browser_popular_test.mjs` проверяет 120 сочетаний маршрута, ширины и темы,
ссылки force viewer, Back/Forward, состояние без JavaScript и reduced motion.
Остальные сценарии проверяют повреждённые данные, WebGL fallback, клавиатуру,
доступность и остановку анимаций. Реальные мобильные устройства, скринридеры
и весь диапазон аппаратных GPU этим не сертифицируются.

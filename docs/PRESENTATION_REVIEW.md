# Final presentation review: scope and evidence availability

This review refines the existing draft Optimization chapter. It does not authorize
publication, a new native scientific run or a claim of optimizer superiority.

## Deliberate presentation changes

The Overview retains its original first-screen typography, palette, molecular
stage and figures. Its closing editorial note now offers a second, explicit
link to Optimization alongside the unchanged essay link. At widths up to 420 px,
the Optimization hero places each numerical result above its explanatory caption
rather than squeezing that caption beside a long decimal. Exact data are unchanged.

Six named containers receive appropriate semantics: the saved-image controls,
atom controls, parameter summary, state chart and conceptual transaction are
named groups; chapter contents is named navigation. The interactive chart is
not an image role that would hide its descendant buttons. These static corrections
also apply with JavaScript disabled. The basis is the W3C ARIA-in-HTML rule that
generic containers cannot receive an accessible name without a permitted role:
https://www.w3.org/TR/html-aria/#docconformance

The refinements are isolated in `site/presentation_review.py` and its stylesheet.
Exact template extension points fail closed when absent or duplicated. Existing
scientific exporters, charts, motion code, all twelve routes and both films remain.
No test is removed or weakened.

## Current availability, not a claim of new verification

The complete private main4500 recovery bundle is currently unavailable after the
previous persistent-save failure and workspace reset. Earlier observations remain
in the reviewed v001 aggregate export and source-hash registry. A hash identifies
bytes; it does not supply missing bytes. This review does not rerun or independently
re-establish the native recovery from unavailable arrays, model states and process
receipts. Its scientific checks verify the committed public arithmetic, original
public datasets and unchanged evidence categories. The page states this limit
visibly before the source downloads, including without JavaScript.

The original M01 package, XI journal and TERMINAL prediction-vector gaps remain.
The historical P1 runtime-capture failure remains a failure. T1 remains synthetic
engineering only; T2, independent external qualification, real-data superiority,
reactive MD and hardware fault tolerance remain unproved. No new native science
is executed by these presentation changes or their tests.

## Manifest precedence

`provenance/PUBLIC_ASSET_MANIFEST.tsv` is retained byte-for-byte as the reviewed
pre-refinement snapshot. `provenance/PRESENTATION_REVIEW_DELTA.tsv` explicitly
supersedes its current-byte fields for only the workflow, full-site builder and selftest manifest integration,
and registers the new review files. It does not override any scientific data,
media, licenses, original source hashes or frozen manifest. The verifier checks
all original registered files plus the explicit additions, refuses duplicate or
unexpected overrides, and checks each previous hash against the retained snapshot.
The original selftest retains its size, hash, duplicate-name and sanitization checks;
its two current-byte comparisons consult the validated delta. No scientific source
or expected numerical result is overridden. Mutation tests reject unauthorized
scope, changed previous hashes and tampered scientific bytes.
The delta does not hash itself; its identity is bound by the Git revision.

## Actual-browser review supplement

`tools/site/browser_review_test.mjs` supplements, rather than replaces, all three
existing runners. It uses the existing locked Puppeteer and axe dependencies.
It records all 120 route/theme/width combinations both before and after refinement,
including full incomplete-rule nodes and computed foreground/background styles.
No incomplete finding is silently counted as an automatic pass. The final report
must adjudicate retained contrast findings or mark manual review incomplete.

The same Chrome captures the frozen main, the previous PR and the proposed tree.
It also tests the new Overview link, twelve stable-pointer play/pause cycles,
static evidence disclosure, and the still-unmodified live site's UTM deep links.
A successful automation status alone is not an accessibility certification or a
substitute for looking at the PNGs. The earlier unexplained pause failure is not
retroactively assigned a cause; new trials only establish their recorded scope.

The workflow retains exact public source, preview and browser receipts for 14 days.
These artifacts and the downloadable handoff are not a promise of permanent Library
storage. No external storage write is required to reproduce the public site.

## What the new figures mean

The Optimization hero is now an observation plate with three **selected** saved
native-J snapshots (S0, S2, S4). Each horizontal row uses the same fixed logarithmic
axis, 10^-5 to 10^-3. Marker positions are generated from the unrounded public
payload. Display values are rounded; exact values remain in the original table
and marker metadata. The caption names the omitted S1, diagnostic branches and
unmeasured S3. This is not a continuous trajectory or a physical-time plot.
The complete pre-existing chart still contains six measured markers and no S3 point.

The coefficient atlas contains exactly one equal-sized decorative square per
nominal coefficient: 216 radial, 29 invariant and three species offsets. A family
selector highlights a group and reads its definition directly from the same
validated payload used by the original chapter. Squares do not encode magnitude,
spatial position, sensitivity, covariance or physical rank. No individual square
creates a keyboard stop. All definitions remain in the static page.

The native-state rail follows only the five native states. It delegates selection
to the existing optimization controller and observes its semantic selected-state
attribute. Diagnostic copies remain separate in the original seven-state reader.
No second playback clock or independent scientific state is introduced.

The candidate transaction has two alternative outcomes, accept or full rollback,
not a sequential accept-then-rollback path. It remains explicitly conceptual.
Neither this schematic nor the saved-row COV result is a real-data optimizer win.
T1 remains synthetic engineering; the unavailable private recovery bundle and all
historical evidence limitations remain visibly disclosed.

Overview retains its first-screen scientific content and renderer. A quiet
three-question reading path connects geometry, off-path evidence and optimization.
Offpath receives an editorial bridge, not a replacement for its completed study.
The saved figures, thresholds, models and old negative conclusions are untouched.

## Interaction and accessibility

New selectors start disabled and become available only after the existing
validated optimization enhancement is ready. Missing or mismatched JSON leaves
all old and new controls safely disabled. The atlas supports native buttons plus
Left/Right/Home/End. The same selected family is conveyed by text, pressed state,
and outline, not color alone. Static state values remain readable without JS.

The skip link focuses the current chapter without routing to Overview. Legacy
play buttons keep their accessible names synchronized with their visible labels.
Heading entrance motion has a reduced-motion and `?still` opt-out; numerical
marker positions do not animate. No runtime library, remote font, new fetch,
continuous timer, synthetic force or model evaluation is added.

The W3C ARIA-in-HTML constraints inform named group/navigation semantics:
https://www.w3.org/TR/html-aria/#docconformance

test_cinematic.py` and the same command with `-O`. Build using the original site
builder. The new `tools/site/browser_cinematic_test.mjs` runs against the built
HTTP site with the existing locked Puppeteer/axe dependencies. It supplements
all prior browser runners and preserves complete axe incomplete results.

actual HTTP-browser authority for the final commit. Every result in the handoff
must name its tested commit/tree; past CI is not evidence of a changed tree.

registers this edition's additions and current-byte changes, without overriding
any frozen scientific source or expected result. Additional tests check the exact
partition, snapshot coordinates, empty S3 value, alternate outcomes, disabled

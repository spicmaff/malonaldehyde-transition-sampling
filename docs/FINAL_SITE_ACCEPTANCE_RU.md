# Финальная приёмка опубликованного сайта

Этот этап продолжает независимую проверку от
`e2a07299e82794e7ffd72ddcb7dada33a2b02b98`. Исторические научные массивы,
модели, определения метрик и четыре предыдущих слоя provenance сохранены.

## Границы и критерий готовности

Готовность сайта означает согласованность опубликованных ресурсов с проверенной
сборкой, работоспособность основных сценариев и соответствие формулировок
доступным доказательствам. Она не означает полную native-воспроизводимость
main4500, экспорт/квалификацию COV-кандидата или сходимость PBE/NEB.
Отсутствующие материалы обозначаются как ограничение конкретного вывода.

Новые физические расчёты не входят в этот этап. Сайт остаётся на английском.
Исходный Site и PR №15 не публикуются и не сливаются; обновляется существующий
приватный `proton-potential-independent-review` с сохранением аудитории.

## Подтверждённое исправление

В статическом графике обучения, доступном без JavaScript, круги имели opacity
0.65. Общие серые точки давали менее 3:1 к светлому фону даже после прежней
правки интерактивного графика. Теперь общий слой имеет opacity 0.75, а
добавленные конфигурации непрозрачны. Координаты, принадлежность и количество
120 отображаемых конфигураций не изменены.

## Воспроизводимые проверки

```sh
python -B tools/audit_independent_science.py --out ../science.json
python -O -B tools/audit_independent_science.py --out ../science-O.json
cmp ../science.json ../science-O.json
python -B -m unittest discover -s tests
node --test tools/site/test_core.mjs tools/site/test_editorial.mjs tools/site/test_payload_validation.mjs
python -B tools/run_public_selftests.py
python -B tools/build_research_site.py --out ../site
```

Выводы сохраняются вне checkout; в средах без `/tmp` задаётся существующий
внешний TMPDIR. Фактические commit/tree и чистота находятся в build-identity.json.

`independent-review.yml` запускается и для ветки `final-site-acceptance`.
Помимо прежних проверок browser suite сохраняет снимки всех 120 комбинаций
12 маршрутов, 5 ширин и 2 тем; научные панели снимаются на всех пяти ширинах.
Для axe incomplete сохраняются computed foreground/background/opacity и
размер текста. Сложные фоны и SVG со sibling graphics требуют визуального
осмотра; их нельзя автоматически объявлять проверенными по одной палитре.
Отдельно проверяется контраст всех 120 статических маркеров без JavaScript.

## Авторизованное сопоставление публикации

`tools/verify_published_site.py` получает конфигурацию через скрытый stdin.
Для каждого Site она содержит точные `project_id`, `url`, `expected_dir`,
`key` и текущий Sites-provided `token`; общий `output_dir` задаёт место отчёта.
Токен не записывается в файл, командную строку, журнал или итоговый JSON.
Не используйте персональные cookies, пароль или токены из сторонних источников.

Скрипт сверяет все записи build-manifest.json и сам manifest с опубликованными
байтами. Допускается только ограниченная цепочка canonical redirects внутри
того же origin. Передача авторизации другому origin запрещена. `.nojekyll`
относится к GitHub Pages, а не к runtime Sites; его отсутствие фиксируется
отдельно и не объявляется отказом приложения. HTTP 401 требует обновления
штатного доступа, а не вывода о недоступности всех материалов.

Итоговые результаты CI, SHA-256 публикации, версия/deployment и границы
визуального осмотра приводятся в отдельном отчёте приёмки.

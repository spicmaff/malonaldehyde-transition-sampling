# Редакция служебных метаданных публикации

Из текущих публичных файлов удалены адреса прежних приватных предпросмотров
и относящиеся к размещению служебные пути. В браузерных проверках сохранён
сценарий открытия страницы с внешним query-параметром, но его значение
заменено на нейтральное `utm_source=review`. Название одного правила поиска
секретов обобщено; регулярное выражение и обнаружение ключей сохранены.

Научные массивы, модели, определения, численные результаты и отображаемое содержание сайта
сохранены. В отчётах опубликованы редакционные копии с пояснением: прежние
адреса опущены, кнопка текущего сайта ведёт на GitHub Pages. Встроенные PNG,
состав приложений и исторические статусы проверок не менялись. Исходные и
экспортные хеши приведены в `reports/site-acceptance-81efe611/PUBLIC_EXPORT.json`;
`SHA256SUMS` и сведения о проверке HTML относятся к новым экспортным байтам.

Пять прежних слоёв provenance и манифест научного заключения сохранены
побайтно. Новый `provenance/PUBLICATION_METADATA_DELTA.tsv` допускает изменения
только восьми перечисленных служебных файлов, проверяет их прежние и текущие
хеши и размеры. Проверки отвергают подмену научного файла или предыдущего
хеша; проверка обнаружения ключей продолжает действовать. История Git не
переписывается; исходные отчёты доступны на родительском commit
`8df2c82d87c9fe2c4884d496fdaa46d3587c2f16`.

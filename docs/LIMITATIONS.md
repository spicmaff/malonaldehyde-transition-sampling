# Limitations

1. PBE is an internal reference, not experimental ground truth.
2. The primary result concerns static fidelity on a fixed reaction path.
3. Converged MTP-NEB at high applicability grade is not evidence of general reliability.
4. MaxVol grade is not a quantitative DFT error.
5. No validated free reactive trajectory was obtained.
6. The H/D audit is one-dimensional and is not an experimental rate model.
7. The basin relaxed path is geometrically invalid.
8. Absolute local paths and private machine identifiers are removed.

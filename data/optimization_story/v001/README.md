# Optimization story: audited public aggregates

This is the sole numerical payload for the additive `#optimization` chapter.
`OPTIMIZATION_STORY.json` drives both static HTML and progressive enhancement.
`CLAIM_DATA_MAP.tsv` maps statements to exact reviewed source fields, units,
evidence classes, access tiers and review checks. `PROVENANCE.json` identifies
the source files by their actual relative locator and SHA-256.

## What can be repeated publicly

The committed numbers permit table arithmetic, native-J differences and ratios,
the signed fixed-D balance, COV saved-row changes, and the END/TERMINAL PBE14
block/region aggregation. A checksum for a restricted source does not distribute
that source. Full native reproduction needs separately available inputs and
licensed software. The public exporter has no private-file fallback.

Four live-state replay outputs reproduced independently retained historical
member hashes. The original M01 archive was not recovered. S1c and S2q are new
declared diagnostic branches; S2q solves ROW_EXACT_FIXED_D. Captured native K
is a separate saved-algebra analysis. S3 remains NOT_MEASURED.

COV numbers describe a constrained correction on saved training rows. Its
candidate was not exported as a model or physically evaluated in the recovery.
T1 is historical synthetic engineering qualification. Necessary input recovery
included one real training process and six detached physical replay processes;
these are separate from T1 and do not constitute T2. Prior missing-journal and
failed runtime-snapshot receipts remain limitations.

## Publication boundary

Only the files named in `PUBLICATION_ALLOWLIST.json` may be copied by the new
chapter builder. No model, checkpoint, source-code package, native binary,
full event journal, geometry/force vector or design matrix is exported here.
Project-owned explanations and aggregate derivatives follow the repository's
existing licensing; no license for external source code is changed.

Engineered and checked on synthetic runs. Not yet demonstrated to be a better
real-data optimizer. PBE14 is development evidence; T2 and independent external
physical validation remain unexecuted.
